# Dynamic Domain-to-Proof Matching Matrix (STAR+R Framework)

When drafting pitches or interview answers, match the role's domain to proven case studies from `.agents/career/projects/` using the **STAR+R** framework (Situation, Task, Action, Result + **Reflection**).

---

## 1. Domain Archetypes & Mapping Guide

### Archetype A: FinTech / Enterprise Admin / Complex State / Auth
- **Focus**: High data consistency, audit trails, role-based access control (RBAC), and low calculation error rates.
- **STAR+R Anchor**:
  - *Situation*: Disjointed records or legacy systems causing error-prone manual calculations.
  - *Task*: Architect a unified, secure enterprise management platform from scratch.
  - *Action*: Implement RBAC, row-level security, automated computation engines, and type-safe server actions.
  - *Result*: Zero calculation errors, 100% audit accuracy, sub-100ms record querying.
  - *+Reflection (R)*: *"Data consistency and idempotent database transactions must always back optimistic UI updates in financial admin systems."*

### Archetype B: 0-to-1 MVP / Direct Client Web Apps / High-Conversion Tooling
- **Focus**: Rapid delivery timeline, high conversion rate optimization, and crisp user experience.
- **STAR+R Anchor**:
  - *Situation*: High-stakes launch or conference deadline requiring interactive conversion tooling.
  - *Task*: Build, test, and ship an interactive tool with lead capture under a tight turnaround.
  - *Action*: Deliver a responsive UI with dynamic client-side math and automated webhook pipelines.
  - *Result*: 100+ qualified leads captured on day 1 with zero frontend downtime.
  - *+Reflection (R)*: *"Tight-turnaround MVP development requires strict scope focus on the 20% core interaction driving 80% of user conversion."*

### Archetype C: AI Applications / Systems / Automation
- **Focus**: Multi-modal AI integration, deterministic workflows, token efficiency, and agent orchestration.
- **STAR+R Anchor**:
  - *Situation*: Repetitive cognitive overhead or complex manual formatting workflows.
  - *Task*: Engineer an AI-assisted pipeline that produces verified structured outputs.
  - *Action*: Design structured prompting, validation schemas, and automated feedback loops.
  - *Result*: 10x faster turnaround, reduced token overhead, and 100% schema validation.
  - *+Reflection (R)*: *"AI tools succeed when they manipulate structured, verifiable data models rather than generating unstructured free-text."*
