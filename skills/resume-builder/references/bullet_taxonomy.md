# Resume Bullet-Point Taxonomy & Google XYZ Guide

This reference provides the structural syntax, action verb taxonomy, impact metrics framework, and anti-hallucination rules for authoring high-impact resume bullet points.

---

## 1. The Google XYZ Formula

Every bullet point MUST follow the Google XYZ formula:

$$\text{Accomplished } [X] \text{, as measured by } [Y] \text{, by doing } [Z]$$

- **[X] Accomplishment**: The technical milestone, feature, or system delivered.
- **[Y] Measured Impact**: Quantified metric, test suite count, latency reduction, lead volume, or business outcome.
- **[Z] Implementation / Action**: The architectural choice, stack, algorithm, or methodology used.

### Transformation Samples (Weak vs. Google XYZ)

| Weak / Task-Focused Bullet | Google XYZ Proof-Anchored Bullet |
| :--- | :--- |
| *Worked on loan calculations and database.* | **Architected loan management portal with CPA-validated amortization engine (X)**, achieving 0 calculation errors and replacing legacy spreadsheets (**Y**), using Next.js, Prisma ORM, and PostgreSQL (**Z**). |
| *Built lead generation quiz for conference.* | **Engineered real-time B2B retreat ROI calculator (X)**, capturing 200+ enterprise leads within a 72-hour turnaround (**Y**), using React, Tailwind CSS, and webhook pipelines (**Z**). |
| *Created packaging label tool.* | **Engineered AI packaging studio and group-buying aggregator (X)**, unlocking $150k commercial value and accelerating turnaround by 10x (**Y**), using Next.js and Supabase PostgreSQL (**Z**). |
| *Developed POS system for retail stores.* | **Engineered zero-custody retail POS with direct wallet routing (X)**, achieving sub-150ms checkout latency and 43/43 passing automated tests (**Y**), using React, TypeScript, and Zustand (**Z**). |

## 2. Strong Action Verb Dictionary

### 2.1 Architectural & 0-to-1 Leadership Verbs
- `Architected`, `Engineered`, `Scaffolded`, `Formulated`, `Pioneered`, `Orchestrated`, `Decoupled`, `Constructed`
- *Usage*: Use for greenfield systems, foundational frameworks, and full-stack platforms.

### 2.2 Performance & Optimization Verbs
- `Accelerated`, `Streamlined`, `Reduced`, `Minimized`, `Compressed`, `Benchmarked`, `Eliminated`, `Consolidated`
- *Usage*: Use when highlighting latency cuts, token savings, cost reductions, or speedups.

### 2.3 Integration, Data & Security Verbs
- `Integrated`, `Synchronized`, `Normalized`, `Enforced`, `Hardened`, `Standardized`, `Automated`, `Migrated`
- *Usage*: Use for API pipelines, RLS security policies, RBAC guards, database migrations, and webhooks.

### 2.4 Commercial & Conversion Impact Verbs
- `Captured`, `Generated`, `Unlocked`, `Scaled`, `Converted`, `Maximized`, `Acquired`, `Delivered`
- *Usage*: Use for lead funnels, ROI calculators, revenue enablement, and startup pitch awards.

## 3. Anti-Hallucination & Verification Checklist

Before compiling a resume bullet point, assert the following:

- [ ] **1. Exact Metric Match**: Does the number exist in `.agents/career/profile.md` or `.agents/career/projects/`? (Reject any invented percentages).
- [ ] **2. Authentic Tech Stack**: Did the candidate use the listed frameworks? (Reject unverified technologies).
- [ ] **3. Active Verb Lead**: Does the bullet start with a past-tense action verb from Section 2?
- [ ] **4. Google XYZ Structure**: Does the bullet clearly answer X (Accomplished), Y (Measured by), and Z (By doing)?
- [ ] **5. Line Length & Density**: Is the bullet 1 to 2 lines maximum (~20–35 words)?
