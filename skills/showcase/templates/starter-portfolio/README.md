# Showcase Starter Portfolio

Welcome to your new personal portfolio. This website is clean, fast, and ready to publish.

It requires **zero build tools** and **zero terminal commands**.

---

## 1. How to Open and Preview

You can open this website immediately:

1. **Double-click `index.html`** in your file manager.
2. The website will open in your default web browser (Chrome, Safari, Edge, or Firefox).

Everything works right out of the box.

---

## 2. How to Publish Online (Free in 2 Minutes)

You can publish your website to the internet for free using Vercel or Netlify:

### Option A: Deploy on Vercel
1. Go to [vercel.com](https://vercel.com) and sign in.
2. Drag and drop this folder into the dashboard.
3. Your website is live with a custom URL.

### Option B: Deploy on Netlify
1. Go to [netlify.com](https://netlify.com) and sign in.
2. Drag and drop this folder into **Netlify Drop**.
3. Your website is live immediately.

---

## 3. Visual Style Presets

This starter template includes 4 visual styles:

1. **Warm Editorial**: Bookish, calm, and trustworthy with serif typography.
2. **Clean Minimal**: Crisp Swiss geometric design with high-contrast lines.
3. **Bold Creative**: High-energy purple accents with expressive modern fonts.
4. **Dark Studio**: Sleek obsidian dark mode with glowing status badges.

You can change the style anytime by changing the `data-theme` attribute on the first line of `index.html`:
```html
<html lang="en" data-theme="warm-editorial">
```

---

## 4. How to Update Your Content

- **Projects**: Edit `data/projects.json` or use the `/showcase publish` skill command.
- **Bio & Contact Info**: Update text directly inside `index.html` or use `/showcase profile`.
- **Resume**: Place your static resume PDF in this folder and link to it.
